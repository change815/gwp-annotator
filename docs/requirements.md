# 胃癌白斑标注 V0.1 需求说明

## 1. 文档状态与范围

本文只定义“胃癌术中白斑标注”Windows 单机软件的 V0.1。它服务于医生从院区病例目录中挑选代表图并圈选白斑区域，不定位为通用标注平台，也不作医疗诊断。

### 当前确认需求

| 主题 | 已确认需求 |
| --- | --- |
| 使用环境 | 医生在 Windows 上使用；软件应轻量，启动和浏览快，默认完全离线。 |
| 输入目录 | 数据根目录下有 1 个或更多院区目录；院区目录可为任意名称（包括中文），每个院区可有病例文件夹。病例文件夹通常含约 10 张 JPG 和 1--2 个 MP4。 |
| 原始数据保护 | 原始 JPG 和 MP4 只读使用，不改写、重命名、移动、删除或向原目录写入任何副文件。 |
| 主工作流 | 选择院区 -> 在侧栏选择病例文件夹 -> 在中央查看照片或视频 -> 用左右方向键浏览 -> 按需选择最清晰、适合训练的代表图 -> 标注。 |
| 代表图 | 医生可按需选择任意数量的代表图；未标为代表图的媒体不得进入标注和训练导出。 |
| 圈选 | 默认工具为自动闭合自由圈选：左键单击一次起点后即可松开，随后移动鼠标记录轨迹；回到起点附近自动闭合；随后显示标签小窗口。圈选中的额外单击不重置草稿，鼠标右键或 `Esc` 取消当前未保存圈选。 |
| 标签窗口 | 小窗口根据正式 TOML 模板生成标签控件，并提供 `OK` / `Cancel`。当前研究模板的全部字段均使用平铺单选；通用解析器仅为历史模板兼容而保留下拉和多选能力。 |
| 保存 | 点击 `OK` 后立即保存本次区域和标签；`Cancel` 丢弃本次圈选。一个代表图可有多个区域。 |
| 视频 | V0.1 可播放浏览 MP4，并可截取当前帧。截帧作为派生图像进入同一代表图和圈选流程；不做视频逐帧追踪。 |
| 标签内容边界 | 医生已确认“浆膜分型”“浆膜白斑分型”“浆膜白斑置信度”及其选项，以 `desktop/templates/label-template-v1.toml` 为准。除该医学负责人提供的模板外，不得臆造或扩充医学选项。 |
| 隐私 | 病例和院区目录名可仅在本机界面显示；标注结果、SQLite、备份、导出、错误日志、Git 和本文档示例必须只使用脱敏 ID，绝不复制真实患者姓名或院区名。 |
| V0.1 排除项 | 不做模型预测、分期输入、强制双人标注、审核、登录、云服务或自动医疗诊断。 |

## 2. 用户流程和行为

1. 医生选择数据根目录后，应用列出其中所有有效院区，并在界面中原样显示本机真实目录名；医生从中选择一个院区。
2. 左侧显示该院区的病例列表；病例按日期降序排列，日期相同则使用稳定的脱敏病例 ID 排序。
3. 医生选择病例后，中部媒体查看器显示该病例的 JPG 与 MP4。左右方向键切换上一项和下一项媒体；焦点位于标签窗口或文本输入控件时，方向键不抢占其输入。
4. 医生可将按需数量的 JPG 或截取帧标记为代表图。已有已保存区域的代表图不能取消选择；其余代表图可取消选择。
5. 医生打开一张代表图，使用默认自由圈选工具完成一个区域。闭合后按外部模板填写标签：模板规定的必填项未完成时，`OK` 不可用。
6. 点击 `OK` 后，区域和标签立即持久化；继续重复可为同一代表图增加多个区域。点击 `Cancel`、鼠标右键或按 `Esc` 时，本次尚未保存的轨迹和标签全部丢弃。
7. 医生可在本机生成训练导出。导出只包含已选代表图及其已保存区域，并使用脱敏 ID 命名。

## 3. 输入、显示与隐私约束

### 3.1 目录约定

输入根目录第一层可有 1 个或更多院区目录，第二层是病例目录。院区目录不受命名规则限制，可包含中文；界面原样显示其本机目录名。根目录中找不到任何“院区 -> 病例”两层结构时才报错；这会识别把常见的扁平病例院区目录误选为根目录的情况。由于目录名不设规则，含额外嵌套目录的任意文件树无法仅凭层级完全推断选择是否正确，界面仍应显示扫描结果供用户确认。不能因院区数量不是两个而报错。下例中的院区名、`CASE` 与 `ASSET` 都是合成占位符：

```text
<数据根目录>/
  CAMPUS-ONE/
    CASE-001/
      ASSET-0001.JPG
      ASSET-0002.JPG
      ASSET-0003.MP4
  院区-乙/
    CASE-002/
      ASSET-0001.JPG
      ASSET-0002.MP4
```

扫描只识别病例目录第一层中的 `.jpg`、`.jpeg`、`.mp4`（大小写不敏感）；不递归扫描其他子目录。扫描阶段只读取目录项和文件元数据，只有医生打开某一媒体时才按需解码该媒体。

### 3.2 脱敏标识

- 软件为每个病例生成稳定、不含姓名的 `CASE-...` ID；结果、导出、缓存文件名和日志只使用该 ID。
- 原始病例目录名只可用于当前本机进程中的侧栏显示和打开对应文件，不能写入标注数据库、标注 JSON、训练导出、截图导出或诊断日志。
- 原始院区目录名只可用于当前本机进程中的院区选择和显示，不能写入 SQLite、备份、日志、Git 或任何导出；院区数量和名称也不能成为拒绝有效根目录的隐含规则。
- 原始媒体的路径、文件夹名和 EXIF 中可能存在的姓名不得写入导出。训练图像导出时必须使用脱敏文件名并移除 EXIF。

## 4. 标签模板需求

正式标签模板采用版本化 TOML，支持以下字段属性：

- `id`：稳定的机器字段 ID。
- `label`：本机界面显示名。
- `control`：当前研究模板统一为 `single_select`；解析器继续兼容历史 `dropdown` 和 `multi_select`。
- `required`：布尔值，决定是否允许 `OK`。
- `options`：带稳定 `id` 和显示 `label` 的选项列表。

正式 TOML 必须是严格 UTF-8 字节流。发生解码错误、出现 Unicode 替换字符 `U+FFFD` 或检测到明显乱码时，导入必须拒绝并提示“请另存为 UTF-8 后重试”；不得猜测 GBK 或其他本地编码，也不得静默转换。该规则适用于首次导入和更换模板。

为便于首次兼容导入，允许简化的 `label.txt`：每行 `[*]字段名=选项A|选项B|...`。星号表示必填；该简化格式一律导入为下拉控件。需要单选或多选以及后续更换模板时，应使用正式 TOML 模板。

模板加载时必须校验字段 ID、选项 ID 的唯一性及必填字段是否有可选项。模板可在明确确认后更换；新区域使用当前模板，旧区域继续保留其原模板快照。同一已用于标注的模板 ID/version 不得以不同内容覆盖。保存标注时记录模板版本和选项 ID，避免模板显示文字改动后丢失历史语义。

## 5. 非功能需求

- 默认不联网；无登录、云同步、遥测或在线模型下载。
- 数据根目录必须以只读方式打开；派生截帧、缩略图、数据库、恢复文件和导出均放在应用自己的项目工作目录。Windows 工作目录跟随安装磁盘，位于安装目录旁的 `GWP Annotator Data`，不写入源病例目录。
- 首次扫描应对包含多个院区、各约 100 个病例、每例约 10 个 JPG 和 1--2 个 MP4 的参考布局保持可用；缩略图和媒体解码均按需加载，不能阻塞病例列表。
- 已点击 `OK` 的标注在进程异常退出后必须可恢复；重新启动时自动加载当前图片的已保存区域，并提供手工重新加载入口。未确认的圈选不得被误标为已保存。
- “完成本病例并备份”只维护一份项目级 `backups/current` 快照，后一次成功备份原子覆盖前一次。正常启动和手工项目重载读取实时主库，不能用较旧备份覆盖主库的新标注。
- 所有保存和导出失败都应显示可操作错误信息，且不能静默丢失已确认标注。

## 6. 后续可选功能（非 V0.1）

- 模板编辑器、模板签名和模板版本迁移助手。
- 区域编辑、撤销/重做、快捷键自定义和病例筛选。
- 更丰富的图像格式、更多视频编码兼容性和批量导入报告。
- 双人标注、审核流、登录、同步、模型辅助建议和研究数据管理。

这些功能均不是 V0.1 的交付条件，不能以占位实现冒充已交付能力。

## 7. 唯一待确认问题

医学负责人已提供首版正式模板，三个字段均为必填平铺单选：

- 浆膜分型：正常型、反应型、突出结节型、扁平结节型、腱状型、多彩弥漫型。
- 浆膜白斑分型：突出型、扁平型、凹陷型。
- 浆膜白斑置信度：50%、80%、100%。

字段 ID、选项 ID 和中文显示值以 `desktop/templates/label-template-v1.toml` 为唯一正式定义；后续变更必须由医学负责人再次确认。
